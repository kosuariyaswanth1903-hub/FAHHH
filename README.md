# FAHH — Charan Raj

A mobile-friendly, Flappy Bird-style campus game starring Charan Raj.

## Play
- **Mobile:** tap the game area to flap.
- **Desktop:** press `Space` or `↑`.
- Pass each book stack to earn one point.
- Avoid the books and the ground.
- Your best score is saved in the browser on that device.

## Files
- `index.html` — page structure
- `style.css` — responsive interface
- `game.js` — gameplay, collision, scoring and local best score
- `assets/charan.png` — supplied character image
- `audio/tap-flap.mp3` — supplied tap/flap recording
- `audio/game-over-voice.mp3` — supplied game-over/results recording

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a public repository named `FAHH`.
2. Upload the **contents** of this folder (keep `index.html` at the repository root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your game URL will be `https://kosuariyaswanth1903-hub.github.io/FAHH/`.

No build step or backend is required.
